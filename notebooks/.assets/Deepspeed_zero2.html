🔍 阶段说明：Ring Reduce-Scatter 的完整步骤与方向

每个 Bucket 都会完整执行一次 Reduce-Scatter，本页按反向传播顺序演示 Bucket 4 → Bucket 3 → Bucket 2 → Bucket 1。通信方向始终固定为 GPU 0 → GPU 1 → GPU 2 → GPU 3 → GPU 0，4 条相邻链路在同一时刻并行传输，接收方在本地执行同名梯度累加。

Step 1: GPU0→GPU1 发送 P3，GPU1→GPU2 发送 P0，GPU2→GPU3 发送 P1，GPU3→GPU0 发送 P2；接收端得到一次累加结果 P+。
Step 2: 继续沿同一方向接力传输累加后的切片：GPU0→GPU1 发送 P2+，GPU1→GPU2 发送 P3+，GPU2→GPU3 发送 P0+，GPU3→GPU0 发送 P1+。
Step 3: 最后一次沿环传输：GPU0→GPU1 发送 P1++，GPU1→GPU2 发送 P2++，GPU2→GPU3 发送 P3++，GPU3→GPU0 发送 P0++；切片到达属主 GPU 后形成 ΣP0~ΣP3。
Scatter: GPU0 只保留 ΣP0，GPU1 只保留 ΣP1，GPU2 只保留 ΣP2，GPU3 只保留 ΣP3，其余梯度副本释放；每个 Bucket 都重复以上完整流程。

🔍 静态总结：真正的 Ring Reduce-Scatter (打散与均分)

当反向传播计算出一个 Bucket (例如 Bucket 4) 后，集群立刻触发 3 步 Ring 通信，方向始终是 GPU 0 → GPU 1 → GPU 2 → GPU 3 → GPU 0：
• Step 1: GPU0→GPU1 发送 P3，GPU1→GPU2 发送 P0，GPU2→GPU3 发送 P1，GPU3→GPU0 发送 P2，并在接收端累加 (+)。
• Step 2: 继续沿同一方向传递刚才累加后的切片 (++)。
• Step 3: 最后一次沿环传递，切片回到属主 GPU，形成满血版梯度 (Σ)。
最终每张卡只保留属于自己的那 1/4 梯度，剩余 3/4 显存瞬间清空！完美跑满卡间带宽。

🔍 阶段总结：Ring All-Gather 的完整步骤与方向

优化器更新结束后，GPU0/GPU1/GPU2/GPU3 分别只持有本地最新参数切片 P0*、P1*、P2*、P3*。All-Gather 的通信方向仍是 GPU 0 → GPU 1 → GPU 2 → GPU 3 → GPU 0，每一步都是把自己已经拥有的最新切片发给下一张 GPU。

Step 1: GPU0→GPU1 发送 P0*，GPU1→GPU2 发送 P1*，GPU2→GPU3 发送 P2*，GPU3→GPU0 发送 P3*；每张卡获得相邻上一张卡的最新切片。
Step 2: 继续沿同一方向接力转发已收到的切片：GPU0→GPU1 发送 P3*，GPU1→GPU2 发送 P0*，GPU2→GPU3 发送 P1*，GPU3→GPU0 发送 P2*。
Step 3: 最后一轮接力：GPU0→GPU1 发送 P2*，GPU1→GPU2 发送 P3*，GPU2→GPU3 发送 P0*，GPU3→GPU0 发送 P1*。
Gather 结果: 3 步后，每张 GPU 都集齐 P0*~P3*，完整模型参数重新同步，可以进入下一轮前向传播。
