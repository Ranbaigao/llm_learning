DeepSpeed ZeRO-2 流程演示

配置：4张GPU | 模型层数：16层 | Bucket分配：每4层为1个Bucket (即4个切片)

阶段 0: 初始状态 (Initialization)
在 ZeRO-2 中，模型参数 (Parameters) 在每张 GPU 上都保存完整的副本（16层）。
但是，优化器状态 (Optimizer States) 和 梯度 (Gradients) 是分片 (Partitioned) 的。
这里将 16 层模型分为 4 个 Bucket，每张 GPU 负责维护其中 1 个 Bucket 的优化器状态。

🔍 深度图解：Reduce-Scatter 过程 (以 Bucket 0 为例)

在反向传播计算出梯度后，各卡不需要获得完整的全量梯度。通过 Reduce-Scatter (通常使用 Ring-Reduce 算法)，GPU 0 到 3 上的 Bucket 0 梯度会被累加（相加求均值），并将最终结果只保存在 GPU 0（归属卡）上。完成后，其他卡释放该 Bucket 的梯度显存。

🔍 深度图解：All-Gather 过程 (参数同步)

当每张卡用自己负责的梯度和优化器状态更新了对应的参数切片后，模型参数在各卡上是不完整的（只有1/4是最新的）。
通过 All-Gather 操作，GPU 0 将最新的 Bucket 0 广播给其他卡，GPU 1 广播 Bucket 1... 最终所有卡都重新拼装出完整的最新模型参数，准备进行下一轮前向传播。
